# Costume Cart Check

Independent US-focused buying guides for costumes, cosplay accessories, wigs,
props, makeup and collectibles.

The site is editorial-first: it uses original checklists, clear commercial
disclosures and no fabricated reviews, discounts or urgency claims.

## Development

Requires Node.js 22 or later.

```bash
npm install
npm run build:pages
```

The static GitHub Pages output is written to `out/`. The public site is
deployed from the repository's `gh-pages` branch.

## Affiliate status

Affiliate tracking links are intentionally not active before the stated
compliance launch date. Editorial content remains available independently of
commercial relationships.
